# Venüs Kafe

Bu proje, Venüs Kafe için geliştirilmiş modern, şık ve turuncu renk paletine sahip bir tanıtım web sitesidir (One-Page).

## 📌 Müşteri Bilgisi
Venüs Kafe, samimi bir mahalle kültürünü modern bir yaklaşımla sunan bir esnaf kafesidir. 

## 🚀 Kullanılan Teknolojiler
- Semantik HTML5
- Modern CSS (Flexbox/Grid, CSS Variables)
- Vanilla JavaScript (Etkileşimler)
- Formspree (İletişim Formu Altyapısı)
- WebP (Görsel Optimizasyonu)
